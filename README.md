# Инвентаризация — приложение для Android

Офлайн-приложение для учёта техники по кабинетам: инвентарный номер, наименование и установленное ПО (офис, ОС, антивирус с количеством лицензий, браузеры). Печать ведомости и пустого бланка на А4, выгрузка в Excel, резервная копия.

- Android 8.0 и новее
- Интернет не нужен, данные хранятся на телефоне
- Списки программ можно менять прямо в приложении: «⋯ Ещё» → «Справочник ПО»

---

## Способ 1. Собрать на GitHub (ничего не нужно устанавливать)

1. Зарегистрируйтесь на <https://github.com> (если ещё нет аккаунта).
2. Нажмите **«+» → New repository**, введите имя, например `inventory`, и нажмите **Create repository**.
3. На странице пустого репозитория нажмите ссылку **«uploading an existing file»**.
4. Распакуйте архив с проектом и перетащите в окно **всё содержимое папки** `inventory-android`, включая папку `.github`.
   > Папка `.github` скрытая. В Windows включите «Вид → Скрытые элементы», на Mac нажмите Cmd+Shift+. в Finder.
5. Нажмите **Commit changes**.
6. Откройте вкладку **Actions**. Сборка запустится сама и займёт 3–5 минут.
7. Когда появится зелёная галочка, откройте на главной странице репозитория справа **Releases** и скачайте `Inventarizaciya.apk`.
   Удобнее открыть эту страницу прямо с телефона и скачать файл туда.

Если вкладка Actions попросит включить сборки, нажмите **«I understand my workflows, go ahead and enable them»**, затем в списке слева выберите «Сборка APK» → **Run workflow**.

## Способ 2. Собрать в Android Studio

1. Установите Android Studio: <https://developer.android.com/studio>.
2. **File → Open** → выберите папку `inventory-android`.
3. Дождитесь, пока студия скачает всё нужное (внизу пропадёт индикатор Gradle sync).
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
   Или подключите телефон по USB с включённой отладкой и нажмите ▶ Run.

## Установка на телефон

1. Скопируйте APK на телефон или скачайте его прямо на телефоне.
2. Откройте файл. Android попросит разрешить установку из этого источника. Разрешите.
3. Нажмите «Установить». На экране появится значок «Инвентаризация».

Новые версии ставятся поверх старой, данные сохраняются: все сборки подписаны одним ключом из папки `keystore`. **Не удаляйте и не меняйте этот ключ**, иначе новую версию придётся ставить только после удаления старой, вместе с данными.

## Где данные и как их не потерять

- Данные лежат во внутренней памяти приложения. Если удалить приложение или нажать «Очистить данные» в настройках Android, записи пропадут.
- Регулярно делайте **«⋯ Ещё» → «Резервная копия»**. Получится JSON-файл, его можно сохранить в загрузки, на Google Диск или отправить себе в Telegram.
- Чтобы перенести данные на другой телефон: сделайте резервную копию, передайте файл и на новом телефоне выберите **«Восстановить из копии»**.

## Печать

«🖨 Печать» → «Ведомость» или «Пустой бланк». Откроется стандартный экран печати Android: выберите принтер или **«Сохранить как PDF»**. Формат А4, альбомная ориентация.
Чтобы напечатать один кабинет, введите его номер в поиск над списком: ведомость печатает отфильтрованные записи, а номер кабинета сам попадёт в шапку.

## Структура проекта

| Путь | Что там |
|---|---|
| `app/src/main/assets/index.html` | весь интерфейс приложения (HTML/CSS/JS) |
| `app/src/main/java/ru/inventory/app/MainActivity.java` | оболочка WebView: хранение, печать, файлы |
| `app/build.gradle` | версия приложения (`versionCode`, `versionName`) и подпись |
| `.github/workflows/build.yml` | автосборка APK на GitHub |
| `keystore/inventory.jks` | ключ подписи (пароль `inventory`) |

Чтобы выпустить новую версию, увеличьте `versionCode` в `app/build.gradle` (например, 1 → 2) и загрузите изменённые файлы на GitHub. Сборка запустится сама.
